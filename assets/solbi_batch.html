주소 목록으로 PDF 받기

주소 입력 → 분석 조건 선택 → 분석·PDF 생성. 화면을 닫아도 서버에서 계속 진행합니다.

1. 분석할 주소

엑셀의 주소 열을 복사해 붙여넣으세요. 같은 주소는 한 번만 분석합니다. 도로명·번지가 맞지 않으면 다른 주소로 대체하지 않습니다.

2. 분석 조건

설치 유형
이격 여유율(%)

설치 면적 중 모듈 사이 간격·점검 통로로 남기는 비율입니다. 기본 10%. 경계까지 채워 배치합니다.

지붕이 여러 동이면

1차 영업용 추정입니다. 설치각·단수·방향은 설치 유형의 기본값을 쓰고, 지붕은 평지붕으로 가정합니다. 지붕 구조·실제 경사, 전기적 스트링 구성과 장비 최신 규격은 별도 검토가 필요합니다. 인버터 수량은 배치 DC 용량과 목표 DC/AC 비율 1.2로 계산합니다.

3. 결과를 받을 이메일

쉼표로 구분해 최대 2개까지 입력하세요. 분석 완료 후 각 수신자에게 같은 PDF를 개별 발송합니다. 비워 두면 다운로드만 제공합니다.

주소 목록 확인
